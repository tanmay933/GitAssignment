## About the Project

This repository was created as part of a Git and GitHub assignment. It contains a simple website with two HTML pages, `index.html` and `about.html`.

The purpose of this project is to practise basic Git operations and understand how version control helps track changes and manage different versions of a project.

## Project Structure

```text
GitAssignment/
├── index.html
├── about.html
└── .gitignore
```

## Git Operations Covered

- Initializing a local Git repository
- Adding files and creating commits
- Creating and switching between branches
- Merging a feature branch into the main branch
- Using `.gitignore` to exclude unnecessary files
- Reverting a previous commit
- Connecting a local repository to GitHub
- Pushing branches to a remote repository
